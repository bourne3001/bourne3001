# 沙隐：Mac 与抓游协作制作

原创暗冷游戏风格恐怖短剧。完整故事：误入明代古村、四次人性选择、证词复原、翻案与逃生。使用抓游本地 MiniMax H3 制作动态视频，时长以剧情完整为准。

## 抓游开始制作

```bash
git clone https://github.com/bourne3001/bourne3001.git
cd bourne3001
```

已克隆过的目录先运行 `git pull --ff-only`。

1. 阅读 [制作交接说明](shayin/00_先读我.md)。
2. 将 [助手任务](shayin/发给抓游助手的任务.md)交给抓游上的制作助手。
3. 先用第一集01-05图验证现有H3工作流，再推进完整影片。
