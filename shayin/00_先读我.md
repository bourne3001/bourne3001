# 沙隐：抓游完整影片制作交接

目标：以本地 MiniMax H3 将关键图生成真实动态镜头，剪辑成从误入古村到翻案逃生的完整原创游戏风格短剧。时长不限，以剧情完整为先。16:9，暗冷青灰与钢蓝，人物与证物可读，中文字幕，四次人性选择主线 A/A/A/A。成片像叙事游戏直播，没有真人主播小窗、浏览量、平台或作者标签。

## 包内内容与真实完成状态

- 完整六集剧本、48镜头台本、人物和场景设定、四个分支与结局、逐镜提示词全部具备。
- 第一集8幅无字关键图已生成，可作为H3首帧；第2至6集共40镜头关键图尚未生成，需按剧本补齐。7个角色的规范多视角角色卡也尚未生成，建议先制作再批量出图。
- 第一集60秒动态分镜MP4仅为氛围、剧情节奏与界面参考，不是H3实拍动态结果。
- 第一集9段WAV对白和mix.wav为临时系统合成配音。完整对白录制表含全部48镜头，第2至6集音频未录制。全剧SRT为旧360秒计划时码，正式剪辑后必须重排。
- API JSON为Mac旧配置结构参考；未在抓游验证，不可直接当成可运行工作流。模型名、编码器、量化格式、LoRA、节点和解码方式必须匹配抓游现有成功工作流。
- 不包含模型权重，不覆盖抓游已有安装，不需要搬运Mac虚拟环境或Mac专用say配音脚本。

## 制作顺序

1. 确认抓游现有H3成功工作流；先用01-05井边图测试一个短动态镜头，验证人物、动作、声音和显存。远程任务此前报告服务端口18888，请现场确认。
2. 用第一集8图试制作第一集。01-02车内图只清晰出现林澈和沈宁，后排周野和唐晓需补反打镜头或重新生成完整首帧。样片村庄偏城堡式构造，正式版收敛为河西走廊小型夯土村落。
3. 为周野、许婉如、许守义、里正补一致性角色参考；按设定核对林澈、沈宁、唐晓发型服装。生成其余40个镜头起始帧，新增必要反打、证物特写与动作连接镜头，数量不限定48。
4. 对照相对路径清单提交H3图生视频。镜头简单、单段完成一个动作；对坠井、救援、处刑、翻案、逃离等复杂动作拆镜。镜头不够长就续生成或增加切镜，不要用长时间静图填充，也不要机械慢放全片。
5. 保留环境音生成，对白在稳定音色方案下制作。需要口型的镜头单独安排同步生成或后期处理；不能把配音覆盖误称为完成口型。
6. 依六集顺序连成完整片，去掉重复片头和重复回顾；四次选择保留读选项、倒计时、选中反馈和后果。不要伪装视频可以真实点击。
7. 后期添加古册、名单、手机文字、离线弹幕、字幕和HUD，避免模型生成乱码。断网前LIVE，断网后REC；最后翻案与逃生完整呈现。
8. 导出完整MP4，另保存可编辑剪辑工程、最终SRT、原始H3镜头、工作流JSON和生成日志。检查音画同步、字幕遮挡、脸和服装一致、动作衔接、证据链以及四人逃生。建议最终1920×1080、24fps；输出尺寸服从实际生成质量，不能仅放大后声称原生1080p。

## 连续性重点

林澈暗红外套；沈宁短发橄榄绿；周野藏蓝夹克与相机；唐晓低马尾芥末黄与收音杆；许婉如浅米明袄靛蓝缘边、左腕束带。不要把唐晓救援时变成沈宁。第一集手机损坏与后续残损缓存对应；翻案需要木闸、账页时间、完整证词和父亲承认，不能只喊她无辜就结束。
